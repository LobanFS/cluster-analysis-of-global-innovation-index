# cluster-analysis-of-global-innovation-index
Проект посвящён кластерному анализу стран на основе показателей Global Innovation Index (GII) за 2022 год.
Используются данные WIPO-GII_2022, содержащие различные метрики, отражающие инновационное развитие стран (инфраструктура, человеческий капитал, креативные товары и др.).
Цель анализа — выделить группы стран со схожими инновационными характеристиками и проинтерпретировать их экономическое и структурное различие.
# Цель и задачи проекта:

## Цель
Разделить страны на кластеры по схожести инновационных показателей и проанализировать полученные группы с точки зрения экономических и региональных особенностей.

## Задачи
Выбор признаков для кластеризации
Отобрать не менее 5 метрических переменных, релевантных инновационному развитию.
Проверить корреляции между ними, исключить сильно зависимые признаки.
Проведение кластеризации разными методами
Применить K-Means, иерархическую кластеризацию и DBSCAN.
Обосновать выбор алгоритмов и определить оптимальное число кластеров (метод “локтя”, silhouette score и дендрограммы).
Интерпретация и описание кластеров
Рассчитать описательные статистики для каждого кластера.
Присвоить кластерам смысловые названия на основе характеристик (например, “Лидеры инноваций”, “Страны с креативным экспортом”).
Построить визуализации: гистограммы, scatter plot, heatmap, дендрограммы.
Апостериорный анализ
Сопоставить результаты кластеризации с категориальными переменными (например, принадлежность к региону, ОЭСР и т.д.).
Интерпретировать распределение стран по группам.

# Основные результаты
Основные результаты
Алгоритмы K-Means и иерархической кластеризации выделили схожие группы стран по уровню инновационного развития.
Алгоритм DBSCAN выявил узкую, но однородную группу стран-экспортёров креативных товаров (Чехия, Китай, Словакия, Венгрия) с экстремально высокой долей экспорта (≈95%).
Значительная часть стран (≈20%) была классифицирована как “аномалии”, что отражает неоднородность инновационных показателей.
Кластеры различаются по структуре экономики, уровню инвестиций в науку и человеческий капитал.
